# Business-analysis-Apex-Oracle-

Sales & Business Analytics (2016-2017) - Oracle APEX Dashboard
📌 Overview
This Oracle APEX application provides an in-depth comparative business analysis between 2016 and 2017, focusing on:

📈 Sales Performance – Year-over-year revenue, profit, and growth trends.

📦 Product Performance – Best/worst-selling products, category trends.

👥 Customer Segmentation – High-value customers, regional purchasing behavior.

📊 Inventory Efficiency – Stock turnover, demand forecasting, and supplier performance.

Built with Oracle APEX, this dashboard helps businesses identify trends, optimize inventory, and improve sales strategies.

🔍 Key Insights (2016 vs. 2017)
1️⃣ Sales Performance
✔ Total Revenue Growth: Compared 2016 vs. 2017 sales trends.
✔ Profit Margins: Identified most profitable quarters.
✔ Regional Sales: Top-performing regions and declining markets.

2️⃣ Product Performance
✔ Top-Selling Products: Ranked products by revenue and units sold.
✔ Category Trends: Compared performance across product categories.
✔ Seasonal Demand: Identified peak sales periods.

3️⃣ Customer Segmentation
✔ Customer Lifetime Value (CLV): Ranked customers by total spend.
✔ Repeat Purchase Rate: Analyzed customer retention.
✔ Geographic Analysis: Purchasing trends by region.

4️⃣ Inventory & Supply Chain
✔ Stock Turnover Ratio: Compared inventory efficiency between years.
✔ Excess Stock Analysis: Identified slow-moving products.
✔ Supplier Performance: Evaluated delivery times and stock availability.

🚀 How to Run the Application
Prerequisites
✔ Oracle Database (11g)
✔ Oracle APEX (18.x or higher)
✔ SQL Developer (for database setup)

Setup Instructions
Import the APEX Application

Download the busines-analysis.sql export file.

In Oracle APEX, go to App Builder → Import.

Upload and install the application.

Load Sample Data (Optional)

Run the provided SQL scripts to populate demo data.

Configure Data Sources

Modify database connections if using a live dataset.

Access the Dashboard

Navigate to the app URL (https://apex.oracle.com/pls/apex/r/life_choices_sk/business-insight-analytics/home).

Page	Description
